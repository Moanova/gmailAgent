## Détails de l'implémentation
- `obtenir_client() -> Mistral` : singleton (instancié au premier appel), clé via
  `env.requis("MISTRAL_API_KEY")` (erreur propre si absente), `timeout_ms=300_000`
  (timeout HTTP 300 s, AGENTS.md §G).
- `avec_retry(operation, *, tentatives=3, base=2.0, dormir=time.sleep)` :
  wrapper générique typé (`TypeVar`) ; retry sur `SDKError` 429 et 5xx
  (conception.md §4.2 : 3 tentatives, backoff exponentiel base 2 s + jitter
  `random.uniform(0, base)`) ; les autres erreurs HTTP (400/401/403/404…) sont
  relancées immédiatement ; épuisement → journalisation `error` et relance de la
  dernière `SDKError`. `dormir` injectable pour les tests sans attente.
- Imports : `from mistralai.client import Mistral` et
  `from mistralai.client.errors import SDKError` — chemin commun aux deux
  familles de versions du SDK (voir investigation mistralai 3.5.0 dans
  SESSIONS.md) ; mypy-propre, runtime-vérifié sur 3.5.0.
- Dépendance : `mistralai>=3.5` (rétabli après épinglage temporaire à 1.9.11,
  non justifié).
