## Détails de l'implémentation
- `src/contracts.py` (6 source files au total après ajout) :
  - `Meta` : enveloppe commune — `run_id: UUID`, `etape: str`, `agent: str`,
    `timestamp: datetime` (`default_factory=lambda: datetime.now(UTC)` ; itération
    ruff UP017 : alias `datetime.UTC` au lieu de `timezone.utc`).
  - `MessageLu` : `id`, `objet`, `expediteur`, `motif` (tous `min_length=1`).
  - `MessageClasse(MessageLu)` : + `categorie: str` (pattern clé logique
    `groupe.cle` — enum dynamique construit en T2.2 depuis le registre, jamais de
    libellé physique en dur), `urgence: Literal["haute", "moyenne", "basse"]`,
    `message_id_rfc` (pattern normalisé, sans `<>`), `empreinte` (pattern SHA-256
    hexa, 64 caractères).
  - `SyntheseClassification` / `SyntheseSpam` / `SyntheseSuppression` : `statut`
    (Literal par agent, cf. conception §2.4.1), `messages` (ou `count` + `ids`
    pour la suppression), `erreur: str | None = None`, `meta: Meta`.
  - `SyntheseEtape` : union des trois synthèses concrètes.
  - `RapportFinal` : `meta`, `synthese_spam?`, `synthese_classification?`,
    `nb_doublons` (ge=0), `statut_global: Literal["succes", "echec_partiel"]`,
    `etape_fautive: str | None`.
  - `model_config = ConfigDict(extra="forbid")` sur tous les modèles (aligné
    avec `additionalProperties: false` des schémas stricts de T2.2).
  - Règles de non-contradiction (cohérence statut/messages/erreur) volontairement
    hors des modèles → `valider_synthese` (T2.3).
  - Sérialisation des checkpoints : `model_dump(mode="json")` (UUID → str,
    datetime → ISO 8601).
