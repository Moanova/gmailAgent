## Plan d'implémentation

1. **`src/report.py`** (nouveau) :
   - `aggreger(syntheses: Mapping[str, SyntheseEtape], nb_doublons: int) -> ResumeRun` —
     déterministe : depuis `synthese_classification` (si présente) → `par_categorie` et
     `par_urgence` comptés sur `messages` ; depuis `synthese_spam` → `spam_deplaces` =
     `len(messages)` si `statut == "deplaces"` ; depuis `synthese_suppression` →
     `corbeille` = `count` si `statut == "supprimes"` ; `doublons` = `nb_doublons` ;
   - `formater_console(rapport: RapportFinal) -> str` — résumé lisible (plusieurs lignes) :
     statut global (+ `etape_fautive` si `echec_partiel`) ; run de tri : spam déplacés,
     total classés, comptes par catégorie (clés logiques) et par urgence, doublons ;
     run de suppression : messages mis à la corbeille. **Aucun libellé physique en dur**
     (clés logiques uniquement).
2. **`pyproject.toml`** : `py-modules += "report"`.
3. **`src/orchestrator.py`** : `from report import aggreger` ; étape `ETAPE_RAPPORT` de
   `lancer_run_tri` → `resume=aggreger(checkpoint.syntheses, nb_doublons=0)` (stub D46) ;
   de `lancer_run_suppression` → `resume=aggreger(checkpoint.syntheses, nb_doublons=0)`.
4. **`src/cli.py`** : `from report import formater_console` ; `_cmd_tri` et
   `_cmd_suppression` impriment `formater_console(rapport)` après le JSON (la ligne
   `run <id> terminé : <statut>` reste).
5. **Tests unitaires** :
   - `tests/unit/test_report.py` (nouveau) : `aggreger` — tri complet (spam `deplaces` +
     classification 2 catégories/urgences → comptes exacts), `aucun_message` → zéros,
     run de suppression `supprimes` → `corbeille=count`, `echec_technique` → zéros ;
     `formater_console` — contient statut, comptes, étape fautive si rejet, aucun
     `Agent/` en dur ;
   - `tests/unit/test_orchestrator.py` — les rapports de `lancer_run_tri` /
     `lancer_run_suppression` contiennent un `resume` cohérent avec les synthèses ;
   - `tests/unit/test_cli.py` — la sortie console contient le résumé (`formater_console`).
6. **Vérifications** (étape 4) : `ruff check src tests`, `mypy src` (strict),
