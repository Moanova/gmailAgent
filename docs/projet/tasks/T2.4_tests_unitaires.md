## Couverture visée

### `test_contracts.py` — T2.1 (modèles Pydantic)
- `Meta` : `timestamp` UTC par défaut, round-trip JSON.
- `MessageLu` : champs requis, chaînes non vides (`min_length=1`), champ interdit rejeté.
- `MessageClasse` : hérite `MessageLu` ; `categorie` accepte une clé logique, rejette un
  libellé physique (`Agent/a-repondre`) et une clé sans groupe ; `urgence` enum
  (`critique` rejeté) ; `empreinte` pattern SHA-256 (64 hexa minuscules) ;
  `message_id_rfc` normalisé (sans `<>`).
- `SyntheseClassification` / `SyntheseSpam` / `SyntheseSuppression` : construction
  valide, `statut` enum par agent (`synthese` rejeté sur spam), `erreur` optionnel,
  champ interdit rejeté, round-trip JSON.
- `RapportFinal` : construction minimale et complète, `statut_global` enum.

### `test_contracts.py` — T2.2 (schémas JSON dynamiques)
- `schema_agent` (3 agents) : `additionalProperties: false` sur tous les objets,
  `meta` exclu (`properties` et `required`), enums dynamiques (`categorie` depuis
  le registre, `urgence` fixe, `statut` par agent), tous les `$ref` résolus, pas de
  `$defs` orphelin, aucun libellé physique en dur.
- Variantes : spam sans `categorie`/`urgence` (MessageLu), suppression sans `$defs`.
- `schema_agent("inconnu")` → `AgentInconnuError`.
- Registre par défaut (`None`) → chargement du vrai `config/labels.yaml`.
- `response_format_agent` : forme SDK (`type: json_schema`, `name`, `strict: true`,
  `schema` identique à `schema_agent`).

### `test_validation.py` — T2.3 (validation programmatique)
- `extraire_json` : JSON noyé dans du texte, accolades imbriquées + chaînes
  échappées, premier candidat malformé sauté, rejets (`ExtractionJsonError`).
- `collecter_ids_reels` : `tool.execution` (arguments str JSON) et `function.call`
  (arguments dict), 5 champs d'IDs (`threadId`, `thread_id`, `messageId`,
  `message_id`, `id`), valeur str ou liste, entrée non-outil ignorée, arguments
  malformés ignorés, déduplication.
- `valider_synthese` : 5 cas valides (classification, spam, suppression,
  `aucun_message`, `echec_technique`) ; rejets C1a/C1b/C1c (non-contradiction),
  C2a/C2b (`aucun_message`), C3a/C3b (complétude), C4 (authenticité, classification
  et suppression), C5 (count ≠ len(ids)), C6 (empreintes, via `model_construct`
  pour bypasser Pydantic et tester le validateur défensif).
- `construire_synthese` : construction valide (3 agents) avec `meta` injecté,
  agent inconnu → `SyntheseInvalideError`, champ interdit → `ValidationError`,
  test cross-module payload conforme au schéma T2.2 → `valider_synthese` OK.
