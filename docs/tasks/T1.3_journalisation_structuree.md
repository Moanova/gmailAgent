## Détails de l'implémentation
- `configurer(run_id, etape=None)` : configure structlog, idempotent (guard) ;
  contexte `run_id`/`etape` posé via `contextvars.bind_contextvars` (porté
  automatiquement par chaque événement) ; niveau depuis `LOG_LEVEL`
  (défaut `INFO`, via `env.optionnel`) ; deux sorties :
  console (`ConsoleRenderer`, lisible en dev) et fichier JSON Lines
  (`logs/gmailagent.log`, surchargeable via `LOG_FILE`, dossier créé si absent,
  ignoré par git) — le JSON alimente les métriques d'observabilité
  (conception.md §4.8).
- `obtenir_logger(nom)` : wrapper typé sur `structlog.get_logger`.
- Chaîne de processeurs : `merge_contextvars` → `add_log_level` →
  `TimeStamper(fmt="iso")` → rendu.
