## Objectif

Le groupement par doublons reste en phase 6.

## Plan d'implémentation

1. **Normalisations** (conception §3) :
   - `normaliser_message_id(valeur)` : minuscules, `<>` et espaces supprimés ;
   - `normaliser_sujet(sujet)` : minuscules, préfixes `Re:`/`Fwd:`/`Tr:` retirés, espaces normalisés ;
   - `normaliser_corps(corps, content_type)` : décodage quoted-printable/base64, HTML → texte
     brut, minuscules, espaces normalisés.
2. **`empreinte_sha256(expediteur, sujet, corps)`** : SHA-256 hex sur le triplet normalisé
   (expéditeur normalisé inclus).
3. **`empreinte_message(message_gmail)`** : recalcul à partir d'une sortie réelle de
   `get_thread` (payload headers Message-ID/Subject/From + body).
4. **Tests unitaires** `tests/unit/test_dedup.py` : vecteurs connus (SHA-256 de référence),
   déterminisme, insensibilité à la casse/espaces/préfixes, décodage base64/quoted-printable.
5. **Vérifications** : `ruff`, `mypy src` (strict, `py-modules += dedup`), `pytest` ;
   kanban → En revue ; commit/push sur demande (règle C).
