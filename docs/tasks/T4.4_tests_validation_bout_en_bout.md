## Objectif
Critère de sortie de la **phase 4** (plan macro) : **étapes 1–2 du pipeline opérationnelles**
(lecture spam + validation + apposition `Agent/valide-spam`).

## Plan

1. **Tests d'intégration** `tests/integration/test_agent_spam.py` (Gmail mocké, Mistral
   mocké) : run `tri` complet avec agent spam simulé —
   - synthèse `deplaces` valide → libellés `Agent/valide-spam` + retrait SPAM appliqués
     (dry-run : journalisés uniquement / `--reel` : exécutés sur le faux service) ;
   - synthèse rejetée (C1–C6) → arrêt propre, rapport `echec_partiel`, motif journalisé ;
   - boîte spam vide → `aucun_message`, run poursuit ;
   - idempotence : 2 runs même `run_id` → agent non rappelé.
2. **Validation dry-run réelle** (poste utilisateur) : `gmailagent tri` (dry-run) avec
   `MISTRAL_API_KEY` exportée — lecture réelle du dossier spam, aucune écriture Gmail ;
   vérifier logs + checkpoint (`syntheses.spam`) + rapport.
3. **Petit périmètre réel** (règle E) : `--reel` sur quelques spams évidents, vérifier dans
   Gmail que seuls les messages certains ont été replacés et étiquetés.
4. **Vérifications** : `ruff check src tests`, `mypy src`, `python -m pytest tests -v` ;
   kanban → En revue ; commit/push sur `dev` sur demande explicite (règle C).
