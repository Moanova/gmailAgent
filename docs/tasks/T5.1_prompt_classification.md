## Objectif
Étendre `src/prompts.py` avec le prompt de l'agent classification. Le schéma strict
`SyntheseClassification` (`statut`, `messages[]` avec `categorie`, `urgence`,
`message_id_rfc`, `empreinte`) est déjà construit dynamiquement par
`contracts.schema_agent(AGENT_CLASSIFICATION, registre)` (T2.2).

## Plan d'implémentation

1. **`PROMPT_CLASSIFICATION` + injection des libellés** : catégories et urgence du prompt
   injectées depuis `config/labels.yaml` via le registre — **jamais de nom de libellé
   physique en dur** ; règles de véracité (ne mentionner que les messages réellement lus
   via `search_threads`/`get_thread` ; boîte vide → `aucun_message`, jamais de classement
   imaginaire) ; chaque message classé doit déclarer `message_id_rfc` (en-tête Message-ID)
   et `empreinte` (SHA-256 normalisée — recalculée ensuite par l'orchestrateur, C6).
2. **Tests unitaires** `tests/unit/test_prompts.py` (complété) : le prompt ne contient aucun
   libellé physique en dur (assert contre les valeurs du registre), contient les enums
   issus du registre et les règles de véracité.
3. **Vérifications** : `ruff check src tests`, `mypy src` (strict), `pytest tests/unit -v` ;
   kanban → En cours → En revue ; commit/push sur demande (règle C).
